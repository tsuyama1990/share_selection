# T1 改善の源泉

質問：この会社の直近の決算で、利益（営業利益・利益率）が増えた（または減った）のは何によるものか。どの型に近いか。

源泉の決め方：決算短信・有価証券報告書の「経営成績」「事業別（セグメント別）の概況」で、会社自身が利益の増減の理由として書いていること（値上げ、数量、コスト、事業の入れ替えなど）を源泉とする。中期経営計画や将来の成長戦略は、直近の利益の理由として書かれていなければ源泉にしない（chokepoint や他のタスクの材料にする）。

型の定義：
- P1 需要到達型：製品が、ある需要の波（AI・半導体・防衛・電力など）に届いている。大手顧客の設備投資の増加が利益を押し上げる。
- P2 自力改善・掛け替え型：売上は横ばいでも、値上げ・コスト削減・事業の入れ替えで利益率が上がる。
- P3 悲観反転型：長い株価の低迷のあと、悪材料が一時的または過大評価だったことが数字に表れ始めた。
- P4 資本是正型：PBR 1 倍割れ・過剰な現金などを、資本政策（還元の強化、資本コストを意識した経営）で是正する。

answer の項目：
- source_type：最も近い型の記号と、決算で書かれた利益の増減の理由を短く（例："P2 値上げの浸透"）。引用（quote）は、その理由が書かれた決算の文をそのまま。
- demand_wave：届いている需要の波。P1 でなければ "unknown"。
- tier：その需要の波に対して何次の供給元か（例："2 次"）。分からなければ "unknown"。
- chokepoint：他社が代替しにくい理由。文書にあるものだけ。
- exposure_pct：その需要向けの売上の割合。文書の表記のまま。
