# 入口の型（Entry Types）設計書

作成：2026-10-13 ／ 状態：**参考資料**（未実装。段階 3 の設計で使う）。`docs/selection_flow.md` の段階 3 で、ここの型（A, B, G, D, C, F）を改善の源泉の型 P1〜P4 の機械的な印として再編する。[データ] 鳥羽洋行の例から、型 A は単独では候補にしない（`docs/hypothesis_map.md`）

根拠の表記：**[原著]** ユーザー提供の『エミン流「会社四季報」最強の読み方』要旨に記載 ／ **[データ]** 2026-10-13 時点の yfinance キャッシュ（3,702 銘柄、足切り通過 474 銘柄）で確認 ／ **[推論]** 設計者の判断で、検証されていない。**[推論]** の記述は、決定の根拠としては弱いものとして読むこと。

## 1. 目的

一次スクリーニングの出力を、エミン流の**買う理由の型**ごとの母集団に分ける。

- 現状の課題 [データ]：`Recommendation_Type` は通過 474 銘柄のうち Quality Value 280、Watch 166、Quality Growth 27、NET-NET 1 で、判断の区別にほとんど使えない。
- 範囲：yfinance のデータで機械的に判定できる型（A, B, G, D, C, F）のみ。E（テーマ／レイヤーマスター）は二次スクリーニング（LLM と一次情報）の担当で、ここでは扱わない。

## 2. 事前調査

### 2.1 データの揃い具合 [データ]（足切り通過 474 銘柄）

| データ | 充足率 | 使う型 |
|---|---|---|
| 出力列 `Net_Cash(Billion)`・`Real_PSR`・`Cash_to_MarketCap_Ratio` | 100% | A |
| 出力列 `PSR`・`PBR`・`Dividend_Yield(%)` | 100% | A, B, C |
| 出力列 `Sales_CAGR(%)` | 99% | G |
| 営業利益 4 期以上 | 99% | D |
| 月足 5 年以上（取得期間は 2000 年以降） | 96% | C, D |
| `heldPercentInsiders` | 100% | F |
| `earningsGrowth` | 91% | C |
| `forwardPE` | 72% | 使わない（欠損が多い） |

### 2.2 原著の実例（第 5 章の 19 銘柄）と、いまの足切り [データ]

足切り（時価総額・流動性 3,000 万円/日・自己資本比率 50%・営業利益率 7%・PSR 2 倍・営業CF > 0）を通るのは 6 銘柄：綜研化学、かどや製油、東洋水産、日本ケアサプライ、新日本空調、第一興商。

落ちた 13 銘柄（判定順で最初に落ちた条件）：

| 落ちた条件 | 銘柄（値） |
|---|---|
| 営業利益率 7% 未満 | 北川鉄工所 4.6%、トピー工業 2.6%、新日本電工 6.7%、artience 5.9% |
| PSR 2 倍超 | ピジョン 2.3、住友ベークライト 2.56、FFRI 17.0 |
| 自己資本比率 50% 未満 | JT 48.5%、DMG 森精機 39.2% |
| 流動性 3,000 万円/日 未満 | 鳥羽洋行、トレンダーズ |
| 現在の JPX 上場銘柄一覧に存在しない | ドラフト、レーサム（理由は未確認） |

補足 [原著]：DMG 森精機（自己資本比率 34.7%）とトピー工業（39.9%）は、原著でも財務基準を満たさない「例外的な選定」とされている。

### 2.3 実例の値の扱い

- [データ][原著] 実例の多くはすでに割安が是正されている。綜研化学の実質PSR は、原著では 0.45 倍、いまは 1.48 倍。
- そのため実例は**合否のテストには使わず、しきい値の目安**として使う。
- [データ] 原著で PSR・PBR の割安を理由に選ばれた 4 銘柄（北川鉄工所、トピー工業、新日本電工、artience）は、いまも実質PSR 0.31〜0.78、PBR 0.45〜0.84。
- [データ] `heldPercentInsiders` は日本ケアサプライ 0.75、かどや製油 0.71。[原著] 日本ケアサプライは三菱商事・ALSOK が親会社。何が含まれる値かは未検証（型 F で検証する）。

### 2.4 現在の足切りと型の関係

- [データ] 上記 4 銘柄はすべて営業利益率 7% の条件で落ちる。ピジョンは PSR 2 倍の条件で落ちる。
- [推論] PSR・PBR の割安で選ぶ銘柄は利益率が低いことが多く、利益率の足切りとは相性が悪い。原著は利益率の基準を明示していない（[原著] 第 2 章の財務基準は自己資本比率・有利子負債と現金・営業 CF。かどや製油は営業利益率 7〜8% で選定）。
- [推論] 東天紅（営業利益率 約 10%）やダイコク電機（17.8%）のように、**稼ぐ力があっても市場の低い期待が正しい銘柄**は、どの財務しきい値でも区別できない。これは二次スクリーニングの判断である。利益率の足切りは、この種の銘柄を落とす役割を果たしていない。

## 3. 全体構成（案）

```
全銘柄
  └─ 安全の足切り（全型に共通）
       └─ 指標の計算（既存の scorers：実質PSR、PBR、配当、CAGR、トレンドなど）
            └─ 型の判定（新設）：A / B / G / D / C / F を独立に判定（複数該当あり）
                 └─ 出力：Entry_Types 列（例 "A,B"）
```

### 3.1 設計上の論点

| # | 論点 | 案 | 根拠 | 出力への影響 |
|---|---|---|---|---|
| D1 | 共通の足切りの範囲 | 時価総額・流動性・自己資本比率・営業CF のみにし、営業利益率 7% と PSR 2 倍を型の条件へ移す | 2.4 の [データ] と [推論]。**本日のユーザー決定（利益率 7%、PSR 2 倍）の見直しになる** | 通過数が増える（実装時に計測） |
| D2 | `Recommendation_Type` | 削除して `Entry_Types` に置き換える。設定の `recommendation:` も削除 | 1 の [データ]。置き換えたら旧来のものは消す方針 | 列が置き換わる |
| D3 | NET-NET（現金 ≥ 時価総額） | 型 A の条件の 1 つにする | [推論] 同じ「現金の価値」を見ている | NET-NET の推奨は A に吸収 |
| D4 | `Total_Score` | 残す（並び順に使う） | 置き換える根拠がまだない | 変化なし |
| D5 | 型にどれも当たらない銘柄 | 空欄のまま出力に残す | [推論] 表計算ソフトで絞り込める | 行数は足切り通過数のまま |
| D6 | 実装の形 | `src/entry_types.py` に 1 型 1 クラス。閾値は config の `entry_types:` から注入。足りない指標は `metrics.py` に純粋関数で足す | 既存の rules / scorers と同じ形 | なし |

抽象化は 2 つ目の実例が出てから作る規則に合わせ、最初のブランチで A と B を同時に入れて、型のクラスと組み立て関数の形を確定させる。

## 4. 型の定義（初期値。すべて config で変更可）

条件はすべて満たす必要がある（AND）。「または」と書いた箇所だけ OR。しきい値は [推論]（原著の数値を目安に設定）。

### A キャッシュリッチ割安
- [原著] 鳥羽洋行（時価総額 183 億円に対し現金 100 億円超、有利子負債ゼロ）、綜研化学（実質PSR 0.45）、新日本空調（実質PSR 0.44）。第 2 章「理想：保有現金 > 時価総額」
- 条件：現金 − 有利子負債 > 0、かつ（実質PSR ≤ 0.5、または 現金 ÷ 時価総額 ≥ 1.0）
- 二次で確認：現金の使い道（[原著] 第一興商は現金を不動産取得に使い、前提が崩れた）、是正のきっかけ

### B 是正待ち割安
- [原著] 北川鉄工所（PSR 約 0.23）、トピー工業（PBR 0.26、PSR 0.1 倍台）、新日本電工（PSR 0.53、PBR 0.57）、artience（PBR 0.62、PSR 0.5）。第 2 章「PSR 1 倍割れ（特に 0.5 倍以下）」「PBR 1 倍割れ」
- 条件：（PSR ≤ 0.6、または PBR ≤ 0.6）、かつ 営業利益 > 0
- 二次で確認：改善の動き（[原著] 中計、社名変更、PBR 1 倍割れ是正）、事業の弱さが構造的か

### G 割安な成長株
- [原著] ドラフト（PSR 0.68、売上 100 億円台に乗せ増収増益予想）
- 条件：売上 CAGR ≥ 18.9%（4 年で 2 倍の水準）、実質PSR ≤ 1.0、営業利益率 ≥ 7%
- 二次で確認：[原著] 市場規模 × 目標シェアによる将来の時価総額の試算

### D 変化の起点（最高益なのに高値の下）
- [原著] 第 4 章ポイント 6「業績が過去最高益更新予想にもかかわらず、株価が過去最高値を抜いていない銘柄は買い」
- 条件：直近の営業利益が取得期間（4〜5 年）で最大、かつ前年より増加、かつ 株価が 2000 年以降の月足最高値より 10% 以上低い
- 注意 [推論]：原著は「予想」の最高益、本設計は「実績」の最高益で代用する。取得期間 4〜5 年での最大であり、真の「過去最高益」とは限らない
- 二次で確認：四季報の見出し（最高益、V字回復など）と来期予想

### C 逆張り（悲観の行き過ぎ）
- [原著] JT（ロシア懸念で低迷、四季報は増益予想、配当 6% 超、月足で移動平均を上抜ける兆候）、ピジョン（中国懸念で長期低迷、配当 5%、財務が鉄壁）
- 条件：株価が 5 年前より低い、配当利回り ≥ 3%、株価 > 12 か月移動平均、`earningsGrowth` > 0（欠損なら該当なし）
- 注意 [推論]：`earningsGrowth` は四季報の増益予想の代わり。yfinance での定義（期間と比較対象）は実装時に確認し、この設計書に追記する
- 二次で確認：悲観が構造的か一時的か（四季報の予想と市場の見方のずれ）

### F 資本の再編（実験的）
- [原著] 日本ケアサプライ（三菱商事・ALSOK が親会社、浮動株が少なく下値が堅い、親会社による再編で 1,000 億円規模も試算）
- 条件：`heldPercentInsiders` ≥ 0.5、PBR ≤ 1.5
- 注意 [推論]：`heldPercentInsiders` に親会社の持ち分が含まれるかは未検証。実装の最初に数銘柄で検証し、結果をこの設計書に追記する。検証で不適と分かれば型 F は入れない
- 二次で確認：親子上場か、親会社の方針、TOB の可能性（EDINET・四季報）

### 型に当てはめなかった実例
- 東洋水産 [原著]：選定のきっかけは「V字回復」の見出し。機械的な条件では捉えられないため、型 D の実例にはしない
- FFRI [原著]：選定の理由は国策と買収されうる時価総額。いまの PSR は 17.0 倍 [データ] で、型 G の条件に合わない
- 住友ベークライト [原著]：テーマ（AI 半導体）と連続最高益の順張り。テーマは型 E（二次）の担当
