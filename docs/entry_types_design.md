# 入口の型（Entry Types）設計書

作成：2026-10-13 ／ 状態：**設計レビュー待ち**（実装前）

## 1. 目的

一次スクリーニングの出力を、エミン流の**買う理由の型**ごとの母集団に分ける。いまの「全条件の直列」では銘柄が残りにくく、Recommendation_Type は Quality Value（353/474）に偏って区別がつかない。型ごとに母集団を持ち、二次スクリーニングの調べ方を型に合わせて変えられるようにする。

範囲：yfinance のデータで**機械的に判定できる型だけ**（A, B, G, D, C, F）。E（テーマ／レイヤーマスター）は二次（LLM と一次情報）の担当で、ここでは扱わない。

## 2. 事前調査の結果（2026-10-13 のキャッシュ）

### 2.1 データの揃い具合（足切り通過 474 銘柄）

| データ | 充足率 | 使う型 |
|---|---|---|
| 現金・有利子負債（貸借対照表） | 100% | A |
| PSR・PBR・配当 | ほぼ100% | A, B, C |
| 営業利益 4期以上 | 99% | D |
| 月足 5年以上 | 96% | C, D |
| `heldPercentInsiders`（親会社・創業家などの保有比率） | 100% | F |
| `floatShares` | 96% | F（参考） |
| `earningsGrowth`（直近の前年比増益率） | 91% | C（業績底打ちの代わり） |
| `forwardPE` | 72% | 使わない（欠損が多い） |

### 2.2 原著の実例と、いまの足切り

原著の実例 19 銘柄のうち、いまの足切りを通るのは 6 銘柄だけだった。

| 落ちた条件 | 銘柄（型） |
|---|---|
| 営業利益率 7% 未満 | 北川鉄工 4.6%、トピー 2.6%、新日本電工 6.7%、artience 5.9%（すべて型 B） |
| PSR 2 倍超 | ピジョン 2.3（C）、住友ベークライト 2.56（テーマ）、FFRI 17.0（G） |
| 自己資本比率 50% 未満 | JT 48.5%、DMG 森精機 39.2%（原著も「例外」として選んだ銘柄） |
| 流動性・データなし | トレンダーズ、ドラフト、レーサム |

**結論：営業利益率と PSR の上限は「安全」の条件ではなく「型」の条件である。** 利益率が低いから PSR が低い、というのが型 B の本質で、共通の足切りに入れている限り型 B は構造的に拾えない。

### 2.3 実例の値（2026-10 時点）とその扱い

原著の実例の多くは、すでに割安が是正されている（例：綜研化学の実質PSR は、原著の 0.45 倍からいまは 1.48 倍）。そのため実例は**合否のテストには使わず、しきい値の目安**として使う。型 B の実例はいまも実質PSR 0.3〜0.8、PBR 0.45〜0.84 で、定義と合っている。大株主比率は日本ケアサプライ 75%、かどや 71% で、親会社・オーナーの持ち分を拾えている。

## 3. 全体構成

```
全銘柄
  └─ 安全の足切り（全型に共通）：時価総額・流動性・自己資本比率・営業CF
       └─ 指標の計算（既存の scorers：実質PSR、PBR、配当、CAGR、トレンドなど）
            └─ 型の判定（新設）：A / B / G / D / C / F を独立に判定（複数該当あり）
                 └─ 出力：Entry_Types 列（例 "A,B"）。いずれの型にも当たらない銘柄も空欄で出す
```

### 3.1 設計上の決定（案）

| # | 決定 | 理由 | 出力への影響 |
|---|---|---|---|
| D1 | 営業利益率と PSR 上限を**共通の足切りから外し**、型の条件に移す | 2.2 の結論 | 通過数が増える（計測して報告） |
| D2 | `Recommendation_Type` と、その閾値設定（`recommendation:`）を**削除**し、`Entry_Types` に置き換える | 偏っていて判断に使えない。置き換えたら旧来のものは消す | 列が置き換わる |
| D3 | NET-NET（現金 ≥ 時価総額）は型 A の一部とする | 同じ「現金の価値」を見ている | NET-NET の推奨は A に吸収 |
| D4 | `Total_Score` は残す（並び順に使う） | 置き換える根拠がまだない | 変化なし |
| D5 | 型の判定は既存の指標を使い、足りない指標だけ `metrics.py` に純粋関数で足す | 計算と判定を分ける（単一責任） | なし |
| D6 | 型は `src/entry_types.py` に 1 型 1 クラスで置き、閾値は config の `entry_types:` から注入する | 基準を足すときはクラスを 1 つ足すだけ（開放閉鎖） | なし |

抽象化の規則（2 つ目の実例が出てから）に合わせ、最初のブランチで A と B を同時に入れて、型のクラスと組み立て関数の形を確定させる。

## 4. 型の定義（初期値。すべて config で変更可）

各型の条件はすべて満たす必要がある（AND）。「または」と書いたところだけ OR。

### A キャッシュリッチ割安（原著：鳥羽洋行、綜研化学、新日本空調）
- 実質無借金：現金 − 有利子負債 > 0
- 実質PSR ≤ 0.5、**または** 現金 ÷ 時価総額 ≥ 1.0（NET-NET）
- 二次で確認すること：現金の使い道（第一興商の教訓）、是正のきっかけ
- 売りの目安：実質PSR 1 倍、または現金が減って前提が崩れたとき

### B 是正待ち割安（原著：北川鉄工、トピー、新日本電工、artience）
- PSR ≤ 0.6、**または** PBR ≤ 0.6
- 営業利益 > 0（黒字。利益率の下限は設けない）
- 二次で確認すること：中期経営計画、社名変更、還元策などの改善の動き
- 売りの目安：PSR 1 倍、PBR 1 倍

### G 割安な成長株（原著：ドラフト、FFRI）
- 売上 CAGR ≥ 18.9%（4 年で 2 倍の水準）
- 実質PSR ≤ 1.0
- 営業利益率 ≥ 7%（成長の質。いまの足切りの値をここへ移す）
- 二次で確認すること：市場規模 × シェアで将来の時価総額を試算する

### D 変化の起点（原著：第 4 章の「最高益なのに最高値の下」、住友ベークライト、東洋水産）
- 直近の営業利益が、取れる全期間（4〜5 年）で最大（最高益）
- 直近の営業利益が前年より増えている
- 現在の株価が、月足の上場来高値より 10% 以上低い（上値の余地）
- 二次で確認すること：四季報の見出し（最高益、V字回復など）と、来期の予想

### C 逆張り・悲観の行き過ぎ（原著：JT、ピジョン）
- 5 年前より株価が低い（長期の低迷）
- 配当利回り ≥ 3%（待つ力）
- 株価が 12 か月移動平均を上回る（反転の兆し）
- 直近の増益率（`earningsGrowth`）> 0（四季報の増益予想の代わり。欠損なら判定しない）
- 二次で確認すること：悲観が構造的か一時的か（四季報の予想と市場の見方のずれ）

### F 資本の再編（原著：日本ケアサプライ、新日本電工）
- 大株主比率（`heldPercentInsiders`）≥ 50%（親会社・創業家が過半）
- PBR ≤ 1.5（再編で価値が顕在化する余地）
- 二次で確認すること：親子上場か、親会社の方針、TOB の可能性（EDINET・四季報）
- 実験的：`heldPercentInsiders` に何が含まれるかを実装時に数銘柄で検証し、結果をこの設計書に追記する

## 5. 実装計画（1 型 1 ブランチ、bonsai-cleanup の手順に従う）

| 順 | ブランチ | 内容 | 新しい指標 |
|---|---|---|---|
| 1 | `refactor/safety-gate` | D1：営業利益率・PSR 上限を足切りから外す（ただし既存の加点・出力列は維持） | なし |
| 2 | `feat/entry-types-ab` | D2・D3・D5・D6 と型 A・B。`Recommendation_Type` を削除 | なし |
| 3 | `feat/entry-type-g` | 型 G | なし |
| 4 | `feat/entry-type-d` | 型 D | 最高益の判定、上場来高値との差 |
| 5 | `feat/entry-type-c` | 型 C | 5 年騰落率 |
| 6 | `feat/entry-type-f` | 型 F（実験的） | なし（info の値を使う） |

各ブランチの完了基準（共通）：
1. 着手前に完了基準を書く（このブランチの型の条件、許される出力の変化、想定する純増行数）
2. 境界値の単体テスト（しきい値ちょうど・前後、欠損値）
3. 検査一式（`scripts/gate.sh`）が通る。行数の予算の引き上げは、コミットに `Budget-Increase: <型の名前>` を付ける
4. 回帰テストの正解データを作り直し、差分が意図した列・行だけであることを確かめる
5. 全銘柄で実行し、型ごとの該当数と代表銘柄、原著の実例（足切りを通るもの）の判定結果を報告する
6. README と `docs/screening_criteria.md` を更新する
7. **出力が変わるので、マージ前にユーザーの承認を取る**
